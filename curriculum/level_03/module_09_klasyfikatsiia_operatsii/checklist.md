# Чекліст класифікації виписки за місяць

## Повнота проходу

- [ ] Пройдено всі рядки виписки, включно зі списаннями.
- [ ] Виписки за всіма підприємницькими рахунками зведено разом.
- [ ] Кожному рядку присвоєно один із типів операції.
- [ ] Жоден рядок не залишився без типу або з типом «навмання».

## Дохід

- [ ] Для кожного рядка доходу названо документ, що підтверджує операцію.
- [ ] Дохід визнано за датою надходження коштів, а не за датою документа.
- [ ] Дохід у валюті перераховано за курсом на дату отримання.
- [ ] Перевірено, що всі розрахунки були в грошовій формі.

## Що доходом не є

- [ ] Транзитні кошти підтверджено посередницьким договором.
- [ ] Повернені покупцям аванси відокремлено від помилкових платежів.
- [ ] Поворотну фінансову допомогу взято на контроль за строком повернення.
- [ ] Помилкові надходження взято на облік для повернення.
- [ ] Внутрішні перекази між власними рахунками не потрапили в дохід.

## Спірне й відкрите

- [ ] Внесення власних коштів позначено окремо й не вирішено самостійно.
- [ ] Рядки, які неможливо класифікувати, виписано в список запитів.
- [ ] Для кожного запиту зафіксовано дату, суму, платника й питання.

## Підсумок місяця

- [ ] Дохід періоду порахований і звірений із записами обліку.
- [ ] Сума за типами дорівнює обороту за випискою.
- [ ] Спірні позиції передано бухгалтеру з поясненням, чому вони спірні.
