# Памʼятка: класифікація виписки

Стисла довідка для щоденної роботи. Друкується на одну сторінку.
Дата актуальності: **2026-09-07**

## Десять типів рядка

| Тип | Дохід? |
|---|---|
| підприємницький дохід | так |
| власні кошти | **питання до бухгалтера** |
| позика | ні |
| поворотна фінансова допомога | ні, якщо повернуто за 12 місяців |
| помилковий платіж | ні, підлягає поверненню |
| повернення покупцеві | не включається до доходу |
| транзитні кошти | лише винагорода |
| комісія | не операція з клієнтом |
| податок | не операція з клієнтом |
| особиста операція | поза підприємницьким обліком |

## Дохід

- **дата** — день надходження коштів; не дата рахунку й не дата акта;
- **форма** — виключно грошова; негрошовий розрахунок = 15% + перехід на загальну;
- **валюта** — офіційний курс НБУ **на дату отримання доходу**.

## Транзит

За договорами доручення, комісії, транспортного експедирування та агентськими доходом є **лише винагорода**.

**Без договору — доходом є вся сума.** Усна домовленість норму не вмикає.

## Позика ≠ фінансова допомога

| | Позика | Поворотна фін. допомога |
|---|---|---|
| Джерело | Цивільний кодекс | Податковий кодекс |
| Проценти | можуть бути | **немає за визначенням** |
| Ключова умова | письмова форма за сумою | повернення за **12 місяців** |

Дивитися треба на зміст, а не на назву договору.

## Повернення vs помилка

| | Повернення покупцеві | Помилковий платіж |
|---|---|---|
| Гроші були доходом? | так, і перестали ним бути | ні, ніколи |
| Підстава | повернення товару, розірвання, лист-заява | норми про помилкову операцію |
| Де шукати | перелік винятків у складі доходу | **не в переліку винятків** |

## Що не зменшує дохід

Комісія банку · сплачений податок · будь-яка витрата.
На спрощеній системі витрати на базу не впливають.

## Рядок, який не класифікується

Ознаки: призначення без документа · платник ≠ сторона договору · сума не збігається з рахунком · відносин із платником немає.

**Дія:** виписати в запити — дата, сума, платник, питання.
**Не робити:** класифікувати навмання. Завищений дохід — теж помилка (ліміт групи).

## Контроль наприкінці

Сума за типами = оборот за випискою.
