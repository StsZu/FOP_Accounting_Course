# Чекліст місячної роботи з рахунком

## Режим рахунку

- [ ] Усі надходження від клієнтів прийшли на підприємницький рахунок.
- [ ] Клієнтам надано реквізити підприємницького, а не особистого рахунку.
- [ ] Корпоративним платіжним інструментом не виплачувалася заробітна плата.
- [ ] Відомо, хто має право здійснювати операції корпоративним інструментом.

## Кожен рядок виписки

- [ ] Для кожного надходження названо документ, що підтверджує операцію.
- [ ] Рядки, що не є операціями з клієнтами, позначено окремо.
- [ ] Перекази між власними рахунками позначено як внутрішній рух.
- [ ] Комісії банку позначено окремо від операцій з контрагентами.

## Призначення платежу

- [ ] У призначенні кожного надходження є документ, період і суть.
- [ ] Рядки з формулюванням на кшталт «оплата» виписано для уточнення.
- [ ] Із постійними клієнтами узгоджено формулювання на майбутнє.

## Еквайринг

- [ ] Суми зарахувань звірено із сумами оплат за відповідні дні.
- [ ] Різницю пояснено звітом еквайра, а не припущенням.
- [ ] Питання дати визнання доходу передано бухгалтеру.

## Спірне — бухгалтеру

- [ ] Внесення власних коштів позначено окремо й не вирішено самостійно.
- [ ] Питання бази доходу при утриманій комісії передано бухгалтеру.
- [ ] Надходження від осіб, які нічого не замовляли, взято на облік для повернення.
