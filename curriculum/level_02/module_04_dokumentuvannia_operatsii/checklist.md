# Чекліст приймання документа від контрагента

## Що це за операція

- [ ] Визначено, яку саме господарську операцію документ підтверджує.
- [ ] Документ звірено з договором: сторони, предмет, сума.
- [ ] Зрозуміло, який період операції охоплює документ.

## Шість реквізитів

- [ ] Назва документа є.
- [ ] Дата складання є.
- [ ] Назва сторони, від імені якої складено документ, є.
- [ ] Зміст, обсяг операції та одиниця виміру зрозумілі з тексту.
- [ ] Посади й прізвища відповідальних осіб зазначено.
- [ ] Є підпис або інші дані, що дають змогу ідентифікувати підписанта.

## Форма й підпис

- [ ] Визначено форму: паперовий оригінал, електронний оригінал, копія чи скан.
- [ ] Для електронного документа підпис перевірено в офіційному сервісі.
- [ ] Зафіксовано результат перевірки: хто підписав, коли, чи не порушено цілісність.
- [ ] Перевірено, чи не використано факсиміле без письмової згоди сторін.

## Дати

- [ ] Дату складання документа записано окремо від дати операції.
- [ ] Для обліку доходу взято дату надходження коштів, а не дату документа.
- [ ] Немає дати, яка суперечить фактичним обставинам операції.

## Що робити з розбіжністю

- [ ] Для кожного відсутнього реквізиту вирішено: неістотний недолік чи відсутній реквізит.
- [ ] Для відсутніх реквізитів надіслано запит на виправлений документ або дублікат.
- [ ] Зафіксовано дату запиту й дедлайн до закриття періоду.
- [ ] Втрачені документи, якщо такі є, взято на облік із датою події.

## Контроль якості

- [ ] Жоден реквізит не оцінено з памʼяті — перевірку зроблено за переліком.
- [ ] Вимоги, яких у переліку немає, не висувалися контрагенту.
- [ ] Документ збережено так, що його можна знайти й пред'явити.
