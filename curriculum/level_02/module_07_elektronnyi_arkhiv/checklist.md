# Чекліст «Архів витримає перевірку»

## Чи є документ

- [ ] За кожним рядком виписки за період названо підтвердний документ.
- [ ] Документи, яких бракує, виписано окремим списком із запитами контрагентам.
- [ ] Рухи коштів, що не є господарськими операціями, позначено окремо.
- [ ] Документи іноземною мовою мають переклад.

## Чи його знайдуть

- [ ] Архів організовано за роками й місяцями, а не за типами документів.
- [ ] Кожен файл має назву з датою, контрагентом і суттю документа.
- [ ] Немає файлів із назвами виду `scan_0043.pdf` або `Документ (2).pdf`.
- [ ] Перевірено на практиці: конкретний документ знаходиться за хвилину.

## Чи можна довести цілісність

- [ ] Для електронних документів збережено протоколи перевірки підпису.
- [ ] Підписані документи не редагувалися після підписання.
- [ ] Чернетки зберігаються окремо від архіву.
- [ ] Формати файлів такі, що документ можна відкрити через три роки.

## Чи переживе носій

- [ ] Архів існує щонайменше у двох копіях на різних носіях.
- [ ] Одна копія зберігається поза основним приміщенням.
- [ ] Перевірено, що резервна копія **відновлюється**, а не просто існує.
- [ ] Синхронізація з хмарою не вважається резервною копією.

## Строки й доступ

- [ ] Строк зберігання визначено за Податковим кодексом, а не за Переліком Мінʼюсту.
- [ ] Для кожного періоду зафіксовано день, від якого рахується строк.
- [ ] Доступ до документів із персональними даними обмежено.
- [ ] Відомо, що робити в перші пʼять днів після втрати документів.
