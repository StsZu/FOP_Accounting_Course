# Глосарій модуля 1

| Термін | Просте пояснення |
|---|---|
| Фізична особа | Людина як учасник правових відносин. |
| ФОП | Фізична особа, державну реєстрацію якої як підприємця внесено до ЄДР. |
| Юридична особа | Окремо зареєстрована організація; ФОП юридичною особою не є. |
| Державна реєстрація | Офіційне визнання державою юридичного факту через внесення запису до реєстру. |
| ЄДР | Державний реєстр юридичних осіб, ФОП і громадських формувань. |
| Виписка з ЄДР | Документ, сформований за результатом реєстраційної дії, з відомостями про зареєстровану особу та дію. |
| Витяг з ЄДР | Документ із відомостями з ЄДР за визначеними параметрами запиту. |
| РНОКПП | Номер облікової картки фізичної особи в Державному реєстрі фізичних осіб — платників податків. |
| Податкова адреса | Місце проживання фізичної особи, за яким її беруть на податковий облік. |
| КВЕД | Код, який класифікує вид економічної діяльності. |
| Основний КВЕД | Вид діяльності, визначений основним у реєстраційних даних. Він не замінює аналіз фактичної діяльності. |
| Основне місце обліку | Контролюючий орган за місцем проживання фізичної особи. |
| Неосновне місце обліку | Облік на іншій території через майно, об’єкт або діяльність, що створює податкові обов’язки. |
| Припинення ФОП | Внесення до ЄДР запису про припинення підприємницької діяльності фізичної особи. |
| Майнова відповідальність | Ризик відповідати за підприємницькими зобов’язаннями майном фізичної особи в межах закону. |
