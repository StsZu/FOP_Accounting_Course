# Пам'ятка: картка профілю ФОП

Стисла довідка для щоденної роботи. Друкується на одну сторінку.
Дата актуальності: **2026-08-15**

## Три статуси, які не можна змішувати

| Статус | Що показує | Чим підтверджується |
|---|---|---|
| Реєстраційний | чи є в особи статус підприємця, КВЕДи, дата й номер запису | ЄДР: виписка або витяг |
| Податковий | система, група, статус ПДВ, місце обліку | витяг або реєстр ДПС |
| Банківський | наявність підприємницького рахунку, IBAN, валюта | документ банку |

Один документ не підтверджує всі три. Висновок «з ЄДР видно групу оподаткування» — типова помилка.

## Реквізити картки й джерела

| Реквізит | Джерело | Типова пастка |
|---|---|---|
| ПІБ | ЄДР | розбіжність із документом, що посвідчує особу |
| РНОКПП або законна альтернатива | документ фізичної особи | вигадати номер «щоб було заповнено» |
| Стан державної реєстрації | ЄДР | застаріла виписка |
| Дата й номер запису | ЄДР | є дата, немає номера — це ще не підтверджено |
| Основний і додаткові КВЕДи | ЄДР | КВЕД ≠ дозвіл на діяльність |
| Податкова адреса | ДПС, ЄДР | плутати з адресою орендованого офісу |
| Основне місце обліку | ДПС | назвати «своєю податковою» за звичкою |
| Можливе неосновне місце обліку | документ на майно | вважати готовим висновком замість приводу до перевірки |
| Система, група, ПДВ | витяг ДПС | брати з ЄДР або зі слів клієнта |
| IBAN і валюта | документ банку | записати з пам'яті клієнта |

## Правило відсутніх даних

Немає підтвердження — пишемо «потрібні дані» і фіксуємо, що саме запросити. Правдоподібне припущення в картці профілю знецінює всю картку: її більше не можна показати як перевірену.

## Що робити з датами

Змінні статуси старіють. Поряд із кожним податковим статусом фіксуйте дату, станом на яку його перевірено. Без дати неможливо довести, що інформація була чинною на момент рішення.

## Межа компетенції

| Питання | Хто веде |
|---|---|
| склад і повнота реквізитів, джерела, дати | бухгалтер |
| конкретний ризик стягнення майна, спірні договори | юрист |
| рішення про припинення чи нову реєстрацію | власник |

## Припинення: що саме завершує запис у ЄДР

Завершує: реєстраційний статус підприємця на майбутнє.
Не завершує: звітність за минулі періоди, розрахунки з бюджетом, договірні зобов'язання, банківські питання, майнову відповідальність.
Закритий запис не відновлюється — для нового старту потрібна нова державна реєстрація.
