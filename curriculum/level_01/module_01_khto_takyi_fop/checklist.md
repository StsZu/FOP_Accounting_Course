# Чекліст базової перевірки профілю ФОП

## Реєстраційні дані

- [ ] Отримано актуальні відомості або документ із ЄДР.
- [ ] Звірено повне ПІБ.
- [ ] Звірено РНОКПП або законну альтернативу.
- [ ] Зафіксовано дату й номер запису державної реєстрації.
- [ ] Перевірено поточний стан запису ФОП.
- [ ] Звірено адресу та зареєстровані КВЕДи.

## Податкові дані

- [ ] Податкову адресу визначено за актуальними даними.
- [ ] Визначено основне місце обліку.
- [ ] Перевірено майно й об’єкти на інших територіях.
- [ ] Систему, групу та ставку підтверджено податковим джерелом.
- [ ] Статус ПДВ перевірено окремо.
- [ ] Зафіксовано дату кожної перевірки.

## Банківські й операційні дані

- [ ] Підприємницькі рахунки підтверджено банківськими документами.
- [ ] Фактичні операції відповідають заявленим КВЕДам.
- [ ] Перевірено можливі ліцензії та спеціальні дозволи.

## Якщо ФОП припинено

- [ ] Перевірено дату запису про припинення.
- [ ] Визначено остаточні звітні обов’язки.
- [ ] Перевірено стан розрахунків із бюджетом.
- [ ] Перевірено договори, дебіторів і кредиторів.
- [ ] Перевірено підприємницькі рахунки та ліцензії.
- [ ] Нову діяльність не ведуть від імені закритого ФОП.

## Контроль якості

- [ ] Жодне відсутнє поле не заповнено припущенням.
- [ ] Не використано реальні персональні дані в навчальних матеріалах.
- [ ] Складні податкові й юридичні питання передано профільному фахівцю.
