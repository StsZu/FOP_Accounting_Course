# Чекліст місячної фінансової самоперевірки ФОП

## Гроші й залишок

- [ ] Отримано виписку за весь період без пропущених днів.
- [ ] Вхідний залишок, надходження, списання і вихідний залишок сходяться.
- [ ] Залишок на рахунку не використано як оцінку прибутку.
- [ ] Відомо, які зобов’язання «сидять» усередині залишку: податки, аванси клієнтів, неоплачені рахунки.

## Класифікація надходжень

- [ ] Кожне надходження має класифікацію, а не лише суму.
- [ ] Для доходу зафіксовано дату його фактичного отримання.
- [ ] Надходження, які доходом не є, виділено окремо із зазначенням причини.
- [ ] Помилкові зарахування виявлено, і по кожному видно ухвалене рішення.
- [ ] Аванси й передоплати позначено, а їх повернення відстежено.
- [ ] Незрозумілі надходження позначено як такі, що потребують запиту, а не класифіковано навмання.

## Особисте й підприємницьке

- [ ] Поповнення власними коштами відокремлено від виручки клієнтів.
- [ ] Перекази між власними рахунками не пораховано двічі.
- [ ] Перевірено, чи не приймалась оплата від клієнтів на особистий рахунок.
- [ ] Зняття коштів на особисті потреби відокремлено від витрат діяльності.

## Заборгованість

- [ ] Складено перелік виконаних робіт, за які оплату ще не отримано.
- [ ] Складено перелік власних невиконаних зобов’язань за вже отриманими коштами.
- [ ] Перевірено, чи є заборгованість, за якою минають строки.

## Контроль якості

- [ ] Жодну операцію не класифіковано припущенням замість документа.
- [ ] У навчальних матеріалах не використано реальні персональні або банківські дані.
- [ ] Питання поза межами класифікації передано бухгалтеру або юристу.
