# Глосарій модуля 2

| Термін | Просте пояснення |
|---|---|
| Дохід | Надходження, отримані від провадження підприємницької діяльності за період. |
| Витрати | Кошти, віддані за ресурси, потрібні для діяльності. |
| Прибуток | Різниця між доходом і витратами за період. |
| Залишок коштів | Сума грошей на рахунку на конкретну дату. |
| Касовий метод | Визнання доходу за датою фактичного надходження коштів. |
| Аванс | Кошти, отримані до виконання роботи або постачання товару. |
| Дебіторська заборгованість | Сума, яку винні вам: робота виконана, оплати ще немає. |
| Кредиторська заборгованість | Сума, яку винні ви: отриманий аванс, неоплачений рахунок. |
| Зобов’язання | Заборгованість, що виникла з минулих подій і погашення якої зменшить ваші ресурси. |
| Актив | Ресурс, контрольований у результаті минулих подій, від якого очікують економічну вигоду. |
| Помилково зараховані кошти | Кошти, зараховані отримувачу без достатньої правової підстави. |
| Неналежний отримувач | Особа, на рахунок якої без законних підстав зараховано суму платіжної операції. |
| Поворотна фінансова допомога | Кошти, отримані в користування за договором без процентів і з обов’язком повернення. |
| Власні кошти підприємця | Гроші тієї самої фізичної особи, внесені нею на підприємницький рахунок. |
| Внутрішній переказ | Рух коштів між власними рахунками однієї особи; нових грошей не створює. |
| Підприємницький рахунок | Рахунок, відкритий фізичною особою для здійснення підприємницької діяльності. |
