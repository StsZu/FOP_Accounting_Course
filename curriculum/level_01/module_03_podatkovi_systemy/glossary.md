# Глосарій модуля 3

| Термін | Просте пояснення |
|---|---|
| Загальна система | Оподаткування чистого доходу ФОП: виручка мінус підтверджені витрати. |
| Спрощена система | Заміна переліку податків на єдиний податок за умови відповідності вимогам. |
| Група єдиного податку | Набір критеріїв, яким треба відповідати одночасно. |
| Обсяг доходу | Дохід за календарний рік, який порівнюють із лімітом групи. |
| Ліміт групи | Кількість розмірів мінімальної зарплати на 1 січня, задана нормою. |
| Фіксована ставка | Ставка першої та другої груп, яку встановлює місцева рада в межах стелі з Кодексу. |
| Відсоткова ставка | Ставка третьої групи: відсоток від доходу. |
| Підвищена ставка | 15% до доходу, отриманого з порушенням умов спрощеної системи. |
| Грошова форма розрахунків | Єдина допустима форма оплати для платника єдиного податку. |
| Поріг реєстрації платником ПДВ | Обсяг постачання за останні 12 календарних місяців, після якого реєстрація обов’язкова. |
| Податковий кредит | Сума ПДВ, на яку платник зменшує своє зобов’язання; недоступна незареєстрованому. |
| Реєстр платників єдиного податку | Офіційне джерело даних про групу, ставку й дату обрання. |
| Витяг з реєстру | Документ із даними реєстру, який видають за запитом безоплатно. |
| Анулювання реєстрації | Виключення з реєстру платників єдиного податку. |
| Чистий оподатковуваний дохід | База ПДФО і військового збору на загальній системі. |
| Військовий збір | Окремий платіж зі своєю базою для кожної системи. |
