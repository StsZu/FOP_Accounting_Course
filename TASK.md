# Поточне завдання

## Назва

Підготувати пілотний модуль 1 «Хто такий ФОП» і перевірити повний виробничий цикл курсу.

## Стан

`app_ready`

## Вхідні матеріали

- `COURSE_CONTENT.md`, модуль 1;
- `TECHNICAL_SPEC.md`;
- офіційні джерела, визначені політикою джерел;
- правила `$fop-course-builder`.

## Послідовність

1. Створити лише потрібні для пілота каталоги, шаблони й реєстр джерел.
2. Визначити перевірювані результати навчання модуля 1.
3. Зібрати й зареєструвати чинні офіційні джерела.
4. Створити урок, практику, кейс, чекліст, глосарій і посилання на джерела.
5. Провести фактологічну перевірку й зафіксувати дати актуальності.
6. Після людської перевірки створити й провалідувати JSON-квіз.
7. Створити шаблон застосунку та зібрати один `index.html` із пілотним модулем.
8. Перевірити офлайн-роботу, мобільний вигляд, прогрес і готовність до GitHub Pages.

## Критерії завершення

- усі податкові та юридичні твердження мають чинні офіційні джерела;
- немає прострочених критичних правил;
- квіз проходить автоматичну перевірку;
- `index.html` працює локально без мережі;
- модуль пройшов людську фактологічну перевірку;
- `STATUS.md` відображає фактичний стан.

## Обмеження

- Не створювати решту 37 модулів до затвердження пілота.
- Не публікувати GitHub Pages без окремого дозволу користувача.
