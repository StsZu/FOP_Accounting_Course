# Виробничий цикл модуля

## Обов’язкові матеріали

- `lesson.md` — пояснення, процес, приклади, ризики й дата актуальності;
- `practice.md` — дія, яку виконує учень;
- `case_study.md` — синтетична робоча ситуація;
- `checklist.md` — контроль виконання;
- `glossary.md` — нові терміни;
- `references.md` — твердження, джерела й дати перевірки;
- `module_meta.json` — ідентифікатор, залежності, версія та стан.

## Порядок

1. Сформулювати 2–5 спостережуваних результатів навчання.
2. Визначити, що учень повинен зробити без підказки.
3. Зібрати офіційні джерела й змінні правила.
4. Написати матеріали простою українською мовою.
5. Додати приклад правильної дії, типову помилку та спосіб її виправлення.
6. Провести фактологічну самоперевірку.
7. Отримати людську перевірку для податкових і юридичних тверджень.
8. Створити сценарний квіз із рівно однією правильною відповіддю, двома правдоподібними дистракторами та окремим feedback для кожного варіанта.
9. Створити інтерактивні мікроперевірки, практику, кейс і чекліст із критеріями завершення.
10. Перевірити JSON і дати актуальності.
11. Повторно зібрати `index.html` і перевірити модуль наскрізь, включно з помилковими відповідями, повторною спробою та збереженням прогресу.

## Заборона переходу

Не переходити до наступного статусу, якщо попередній етап не підтверджений файлами або результатом перевірки. Статус `released` потребує чинних джерел, людської перевірки, валідного квізу та успішної HTML-збірки.
