# Бухгалтер ФОП: від нуля до професійного рівня

Україномовний навчальний курс обліку та оподаткування ФОП. Публічний артефакт — один автономний файл `index.html` у корені репозиторію: він працює офлайн через `file://` і публікується на GitHub Pages без додаткових налаштувань.

**Курс онлайн:** https://stszu.github.io/FOP_Accounting_Course/

Зараз опубліковано 1 модуль із 38 запланованих. Стан кожного модуля — у `STATUS.md`.

## Швидкий старт

```bash
python3 scripts/build_course.py        # зібрати index.html
open index.html                        # відкрити курс
```

Залежностей і збірочних інструментів немає: потрібні лише Python 3 і Node (для тестів), обидва зі стандартної бібліотеки.

## Перевірки

```bash
python3 scripts/check_course.py        # структура модулів, джерела, квізи, дати актуальності
python3 scripts/build_course.py        # складання
node tests/logic_smoke.mjs             # логіка зібраного застосунку без браузера
python3 tests/test_multimodule.py      # багатомодульне складання й негативні сценарії
```

`check_course.py` виконує один прохід по всіх модулях і всередині запускає `validate_quiz.py` для кожного квізу та `check_freshness.py` для дат актуальності.

## Як влаштований курс

```text
course_meta.json                       версія курсу, рівні, підсумкова атестація
curriculum/level_XX/module_YY_slug/    Markdown-матеріали + JSON інтерактивних вправ
quizzes/modules/module_YY_quiz.json    сценарні квізи
sources/SOURCE_REGISTER.md             реєстр офіційних джерел (SRC-NNN)
app/index.template.html                оболонка застосунку: HTML, CSS, vanilla JS
scripts/build_course.py                вбудовує весь контент у index.html
templates/                             шаблони уроку, вправ, джерела, рев’ю
tests/                                 автоматичні перевірки
review/                                людські перевірки й реєстри дефектів
```

Модулі знаходяться автоматично обходом `curriculum/level_*/module_*/module_meta.json`. До збірки потрапляють лише модулі зі статусом `app_ready` або `released` — решта пропускається з повідомленням.

## Правила, які легко порушити

- `index.html` і `index.html` — згенеровані файли. Правити треба шаблон, дані модуля або скрипт складання.
- Шаблон не повинен містити тексту конкретного модуля: усе module-specific живе в `module_meta.json` і JSON-вправах.
- `initial_order` у кейсі не може дорівнювати порядку `actions` — інакше учень отримує бали без роботи. Складання це блокує.
- Жодних зовнішніх залежностей: ні CDN, ні шрифтів, ні аналітики, ні мережевих запитів.
- Податкові й юридичні твердження — лише за офіційними першоджерелами, з датою перевірки та ID у реєстрі джерел.
- Квіз створюється після фактологічної перевірки уроку й людського рев'ю.
- Публікація курсу — тільки з окремого дозволу власника проєкту.
